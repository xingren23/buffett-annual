```
<年份>/
├── index.md                  # 年度概览：会议信息、快速入口、关键事件、主题索引、来源与口径、已知缺口

│   ├── qNN-<slug>.md         # 一个提问一个文件
│   └── aNN-<slug>.md         # 非提问附件（一季报简报、重大宣布等）
└── afternoon/                # 下午场，结构同上
```

每个问答片段的结构固定为：题头表（场次／时间戳／提问者／CNBC 章节／视频链接／主题标签）→ 问题 → 回答要点 → 关键引述（英文原句 + 中译）→ **中文全文（逐段翻译）** → 英文原文 → 返回索引。

## 建议阅读顺序

1. 先读**年度概览**（`<年份>/index.md`）：当天谁在台上、发生了什么、哪些片段值得看；
2. 再看**上／下午索引**：按主题、提问者或时间戳挑问题；
3. 点进具体片段：只读「问题 + 回答要点 + 中文全文」即可，需要核对措辞时看末尾的「英文原文」；
4. 想读当年致股东信，直接开 `shareholder-letter-zh.md`，需要引原文时对照 `shareholder-letter-en.md`；
5. 想比较同一个话题在不同年份的说法，用上面的**跨年度主题索引**，一行读完八年。

- **时间戳是视频内的相对时间**，不是当天钟表时间；片段切分与时间轴对齐 CNBC 官方章节。
- **中文全部是整理稿**：要点为提炼，全文为逐段翻译，均非官方译本；引用请以原文和官方视频为准。
